# Quickstart — Wave C Flagship Program Whitepaper

```bash
git clone https://github.com/ttracx/thox-wave-c-paper.git
cd thox-wave-c-paper
```

Read the paper:

```bash
open paper/THOX_Wave_C_Flagship_Program_Whitepaper_v0.5.0.pdf        # macOS
xdg-open paper/THOX_Wave_C_Flagship_Program_Whitepaper_v0.5.0.pdf    # Linux
```

Run the interactive GATE49 explorer demo (single file, offline):

```bash
open paper/WaveC_Demo_v0.5.0.html
```

Check the evidence behind a printed number:

```bash
# The single evidence source, with per-file source hashes inside it:
less artifact/exp/results/summary.json
# The independent re-verification record for this edition:
ls artifact/wp/qa/
```

Cite it: `CITATION.cff` or `paper.bib` at the repository root.
DOI: [10.5281/zenodo.23969809](https://doi.org/10.5281/zenodo.23969809).
